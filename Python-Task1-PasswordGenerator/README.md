# Python-Task1-PasswordGenerator

**Oasis Infobyte Internship — Task 1**

A simple and customizable Random Password Generator built using Python.

## Features
- Custom password length
- Include or exclude letters, numbers, and symbols
- Password strength indicator (Strong/Medium/Weak)
- Input validation for password length

## Technologies Used
- Python
- `random` module
- `string` module

## How to Run
1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python password_generator.py
```

5. Enter the desired password length and choose which character types to include.

## Sample Output
The program displays the generated password and a password strength indicator in the terminal.
