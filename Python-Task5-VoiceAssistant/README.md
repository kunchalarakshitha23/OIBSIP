# Voice Assistant – Python Task 5

## About
This project is a voice assistant developed using Python to perform simple tasks through voice commands.

## Features
- Accepts voice input from the user.
- Processes supported commands.
- Provides responses to the user.

## Requirements
- Python 3
- Additional Python libraries required by the program

## How to Run
1. Install the required libraries used in `voice_assistant.py`.
2. Run `python voice_assistant.py`.
3. Follow the prompts and try the supported commands.
