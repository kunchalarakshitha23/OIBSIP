# Chatbot – Python Task 4

## About
This project is a simple chatbot developed using Python. It interacts with users through text-based conversations.

## Features
- Accepts messages from the user.
- Responds to basic greetings and questions.
- Provides a simple conversational experience.

## Requirements
- Python 3

## How to Run
1. Open a terminal in the project folder.
2. Run `python chatbot.py`.
3. Type a message and follow the prompts.
