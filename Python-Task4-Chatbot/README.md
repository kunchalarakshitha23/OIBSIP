# Python-Task4-Chatbot

**Oasis Infobyte Internship — Task 4**

## About
This project is a simple text-based chatbot developed using Python. It interacts with users by responding to basic greetings, questions, and commands.

## Features
- Accepts messages from the user
- Responds to greetings such as hello and hi
- Answers basic questions
- Provides a help response
- Exits when the user types `bye`
- Handles unrecognized messages

## Requirements
- Python 3

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python chatbot.py
```

4. Type a message and follow the chatbot's responses.
5. Type `bye` to exit the chatbot.
