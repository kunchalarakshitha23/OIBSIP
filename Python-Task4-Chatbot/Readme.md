# Chatbot Application

## Project Description
This is a simple AI-powered chatbot built using Python and Streamlit. It allows users to interact with an AI chatbot and receive responses to their questions.

## Technologies Used
- Python
- Streamlit
- Groq API
- Python-dotenv

## Installation
Install the required libraries:

pip install -r requirements.txt

## How to Run
Run the following command:

streamlit run app.py

## Features
- Interactive chat interface
- AI-generated responses
- Easy-to-use application
