# Weather App

## Project Description
This is a Python-based Weather App that retrieves current weather information for a city using the OpenWeatherMap API.

## Features
- Enter a city name.
- Display temperature.
- Display feels-like temperature.
- Show humidity and weather conditions.
- Display wind speed.
- Handle empty city names and API key errors.

## Requirements
- Python
- requests library
- OpenWeatherMap API key

## Installation
Install the required library:

```bash
pip install requests
```

## How to Run
Run the following command in the terminal:

```bash
python weather_app.py
```

Enter a city name and provide your API key when prompted.

## Output
The application displays the current weather information for the entered city.
