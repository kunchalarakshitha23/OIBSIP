
# Python Task 3 - Weather App

## About
A Python application that fetches live weather information for a city using the OpenWeatherMap API.

## Features
- Enter a city name
- Display temperature in Celsius
- Display feels-like temperature
- Display humidity
- Display weather conditions
- Handle invalid city names and API errors

## Requirements
- Python
- requests library
- OpenWeatherMap API key
- Internet connection

## Installation
Install the required library:

pip install requests

## How to Run
Run weather_app.py using Python.
Enter the city name and a valid API key when prompted.
