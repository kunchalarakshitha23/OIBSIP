# Python-Task3-WeatherApp

**Oasis Infobyte Internship — Task 3**

## Project Description
This is a Python-based Weather App that retrieves current weather information for a city using the OpenWeatherMap API.

## Features
- Accepts a city name from the user
- Displays temperature and feels-like temperature
- Shows humidity and weather conditions
- Displays wind speed
- Handles empty inputs, invalid API keys, and city-not-found errors
- Handles request timeouts and connection errors

## Requirements
- Python
- `requests` library
- OpenWeatherMap API key

## Installation
Install the required library:

```bash
python -m pip install requests
```

## How to Run
Run the following command in the terminal:

```bash
python weather_app.py
```

Enter the city name and provide your API key when prompted.

## Output
The application displays the current weather information for the entered city.
