# OIBSIP - Python Programming Internship

Welcome to my Python Programming Internship Projects repository!

This repository contains five Python projects developed as part of my Oasis Infobyte Internship (OIBSIP).

## Projects

### 1. Password Generator
A Python application that generates random passwords based on user-selected criteria.

### 2. BMI Calculator
A simple application that calculates Body Mass Index (BMI) and displays the corresponding health category.

### 3. Weather App
A weather application that fetches real-time weather information using a weather API.

### 4. Chatbot
An interactive chatbot built using Python, Streamlit, and Groq API.

### 5. Voice Assistant
A Python-based voice assistant that recognizes voice commands and performs basic tasks.

## Technologies Used

- Python
- Streamlit
- Groq API
- Requests
- Speech Recognition
- pyttsx3

## Installation

1. Clone this repository:
   `git clone https://github.com/kunchalarakshitha23/OIBSIP.git`

2. Open the project folder.

3. Install the required dependencies using:
   `pip install -r requirements.txt`

4. Run the required Python project.
