# OIBSIP - Python Programming Internship

Welcome to my Python Programming Internship Projects repository!

This repository contains Python projects developed as part of my Oasis Infobyte Internship (OIBSIP).

## Internship Tasks

### 1. Voice Assistant
A Python-based voice assistant that recognizes voice commands and performs basic tasks.

### 2. BMI Calculator
A simple application that calculates Body Mass Index (BMI) and displays the corresponding health category.

### 3. Random Password Generator
A Python application that generates random passwords based on user-selected criteria.

### 4. Basic Weather App
A weather application that fetches weather information using a weather API.

## Additional Project

### Chatbot
An interactive chatbot built using Python, Streamlit, and Groq API. This is listed as an additional project and is not being labelled as the PDF's Chat Application task.

## Technologies Used

- Python
- Streamlit
- Groq API
- Requests
- Speech Recognition
- pyttsx3

## Installation

1. Clone this repository:
   `git clone https://github.com/kunchalarakshitha23/OIBSIP.git`

2. Open the required project folder.

3. Install the dependencies listed in that project's `requirements.txt`, if provided.

4. Run the required Python project.
